### **Common Math Symbols**

| Description               | LaTeX Code          | Example Output             |
| ------------------------- | ------------------- | -------------------------- |
| Subscript                 | `x_i`               | $x_1$​                     |
| Superscript                | `x^2`               | $x^2$                      |
| Fractions                 | `\frac{a}{b}`       | $\frac{a}{b}$​             |
| Square Root               | `\sqrt{x}`          | $\sqrt{x}$                 |
| Summation                 | `\sum_{i=1}^n`      | $\sum_{i=1}^n$             |
| Integral                  | `\int_a^b`          | $\int_a^b f(x)=2x^2-3x+2$​ |
| Greek Letters             | `\alpha, \beta \pi` | $\alpha \beta \pi$         |
| Greek Letters (Uppercase) | `\Gamma, \Delta`    | $\Gamma \Delta$            |
| Infinity                  | `\infty`            | $\infty$                   |
| Prikkprodukt              | `a\cdot b`          | $a\cdot b$                 |
| Produktet av en rekke     | `\prod`             | $\prod$                    |

## Symboler

Vanlige symboler kan vi finne i knappene i formeleditoren, men det tar ofte lang tid, og det er raskere å lære seg hurtigtastene for dem. Koden for de ulike symbolene er veldig lik LaTeX-kode.

Aktuelle koder:

| Kode             | Resultat | Kode        | Resultat |
| ---------------- | -------- | ----------- | -------- |
| `\in`            | $\in$    | `\pm`       | $\pm$    |
| `>=`             | $\geq$   | `\infty`    | $\infty$ |
| `<=`             | $\leq$   | `\wedge`    | $\wedge$ |
| `/=`             | $\neq$   | `\cdot`     | $\cdot$  |
| `\leftarrow`     | $\leftarrow$ | `\cup`  | $\cup$   |
| `\Leftarrow`     | $\Leftarrow$ | `\sqrt` | $\sqrt{\phantom{x}}$ |
| `\rightarrow`    | $\rightarrow$ | `\subseteq` | $\subseteq$ |
| `\Rightarrow`    | $\Rightarrow$ | `\vee` | $\vee$   |
| `\Leftrightarrow` | $\Leftrightarrow$ | `\degree` | $\degree$ |

## Greske bokstaver

Hvis du kjenner navnet på den greske bokstaven, så skriver du det med \ foran, og skiller med stor eller liten førstebokstav. Eksempler:

| Kode      | Resultat  |
| --------- | --------- |
| `\alpha`  | $\alpha$  |
| `\beta`   | $\beta$   |
| `\gamma`  | $\gamma$  |
| `\Delta`  | $\Delta$  |
| `\pi`     | $\pi$     |
| `\sigma`  | $\sigma$  |
| `\Sigma`  | $\Sigma$  |

## Doble bokstaver til tallmengder

| Kode           | Resultat     | Betydning      |
| -------------- | ------------ | -------------- |
| `\mathbb{N}`   | $\mathbb{N}$ | Naturlige tall |
| `\mathbb{Z}`   | $\mathbb{Z}$ | Heltall        |
| `\mathbb{Q}`   | $\mathbb{Q}$ | Rasjonale tall |
| `\mathbb{R}`   | $\mathbb{R}$ | Reelle tall    |

> `\doubleN/Z/Q/R` var Words snarveier i formeleditoren og er ikke gyldig LaTeX. I Obsidian bruker du `\mathbb{...}` i stedet.
